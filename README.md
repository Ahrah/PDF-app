# 견적함 - 프리랜서 견적서/청구서

프리랜서를 위한 간편한 견적서 및 청구서 관리 도구입니다.

## 🎉 30일 무료 체험

회원가입 시 30일간 프리미엄 기능을 무료로 체험할 수 있습니다.

### 체험 혜택
- ✅ 무제한 문서 생성
- ✅ 워터마크 제거
- ✅ 모든 프리미엄 기능 이용

### 체험 종료 후
- 월 3건 무료 생성 가능
- 무료 플랜 PDF에는 워터마크 포함
- 프리미엄 플랜: 월 9,900원 (결제 기능 준비 중)

**⚠️ 중요:** 30일 체험 종료 후 자동 결제되지 않습니다. 결제 기능이 없으므로 별도의 구독 취소가 필요하지 않습니다.

## 주요 기능

- ✅ 견적서 및 청구서 생성
- ✅ 한글 폰트 지원 (NanumGothic)
- ✅ PDF 다운로드 및 공유
- ✅ 회원가입 및 30일 무료 체험
- ✅ 무료 플랜: 월 3건 (견적서+청구서 = 1건)
- ✅ 프리미엄 플랜: 무제한 + 워터마크 제거

## 시작하기

### 환경 변수 설정

프로젝트 루트에 `.env.local` 파일을 생성하고 다음 내용을 추가하세요:

```bash
# JWT 세션 암호화 키 (필수)
# 아래 명령어로 생성할 수 있습니다:
# node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
AUTH_SECRET=your-generated-secret-here
```

**AUTH_SECRET 생성 방법:**

```bash
# Node.js를 이용한 랜덤 시크릿 생성
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"

# 또는 OpenSSL 사용
openssl rand -base64 32
```

### 설치 및 실행

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build

# 프로덕션 실행
npm start
```

## 회원가입 및 로그인

### 회원가입
1. 우측 상단 "회원가입" 버튼 클릭
2. 이메일과 비밀번호(6자 이상) 입력
3. 개인정보 수집 및 이용 안내 확인
4. 이용약관 및 개인정보처리방침 동의
5. 회원가입 완료 시 자동으로 30일 무료 체험 시작

### 로그인
1. 우측 상단 "로그인" 버튼 클릭
2. 가입한 이메일과 비밀번호 입력
3. 로그인 성공

## 데이터 저장

### 중요 - 데이터 보관 방식
현재 버전은 로컬 파일 시스템(`/data/db.json`)에 데이터를 저장합니다.

**⚠️ Vercel 배포 시 주의사항:**
- Vercel의 파일 시스템은 일시적이며, 새로운 배포 시 초기화됩니다
- 프로덕션 환경에서는 데이터가 배포 간 유지되지 않습니다
- 향후 업데이트에서 영구 스토리지(데이터베이스)로 전환 예정입니다

**현재 저장되는 정보:**
- 사용자 계정 정보 (이메일, 암호화된 비밀번호, 체험 종료일)
- 고객 정보
- 견적서/청구서 데이터
- 판매자 정보
- 월간 사용량

## 기술 스택

- **프레임워크:** Next.js 15
- **언어:** TypeScript
- **스타일링:** Tailwind CSS
- **PDF 생성:** jsPDF
- **인증:** JWT (jose) + bcryptjs
- **데이터 저장:** 로컬 파일 시스템 (JSON)
